姓名判断の結果がサイトで違うのはなぜ？
名字1,200個と名前で数えました

数え方を変えるだけで、約半数の名前で吉凶が変わりました。いちばん効くのは新字体か旧字体かではなく、部首を元の字で数えるかどうかです。五格に凶が1つもない人は6人に1人でした。

先に結論

  • 名字1,200個と名前を組み合わせて数えると、数え方を変えるだけで2025年の人気の名前の57.8%、1912年以降の各年ベスト10の名前の51.1%で、人格・地格・総格のどれかの吉凶が変わりました
  • いちばん効くのは、新字体か旧字体かよりも、部首を元の字で数えるかどうかです。「艹」を3画と数えるか6画と数えるかだけで、2025年のランキング上位の名前の27%で画数が変わります
  • 吉凶の表の違いは意外と小さく、7つの公開表は1〜25画ですべて同じでした
  • 五格に凶が1つもない人は、今の字で16.7%だけです。6人に5人は、どこかに凶があります
  • ただし「数え方を変えれば凶は消える」とも言えません。12通りのどれで数えても凶が残る人が70.5%います。変わるのは「どの格が凶か」です

1. 部首を元の字で数えるか(いちばん大きい)

「氵」は「水」が略された形なので4画と数える、「艹」は「艸」なので6画と数える、という数え方です。「草」は見たままなら9画、元の字で数えると12画になります。この違いだけで、人格・地格・総格のどれかの吉凶が52.2%の名前で変わります。名前によく使う部首ほど、影響が大きくなります。

2. 新字体か旧字体か

「沢」は7画、旧字体の「澤」は16画です。「広」と「廣」は5画と15画です。差は大きいのですが、旧字体がある字は限られるので、これだけで吉凶が変わるのは14.3%です(全世代では19.8%。昔の名前に多い「恵」「実」「栄」などには旧字体があります)。

3. 霊数を足すか

姓や名が1文字のとき、仮の「1」を足す流派があります。足さない、外格だけに足す、天格・地格・外格に足す、などに分かれます。全体で見ると姓か名が1文字の人は33.4%で、その人たちだけで見ると、天格・地格・外格に足したときに91.3%の五格のどこかの吉凶が変わります。

4. 「々」と漢数字

「佐々木」の「々」を3画と数えるか、前の字と同じ7画と数えるかで、天格は14画(凶)と18画(吉)に分かれます。漢数字は「九」を2画でなく数の値の9とする数え方があります。康熙字典で数えると、部首以外でも今の字と画数が違う字があります(「之」は3画が4画、「蓮」は13画が17画、「泰」は10画が9画)。

5. 吉凶の表

7つの公開サイトの1〜81画の表を、吉・半吉・凶の3つに分けて比べました。流派の公式の表ではなく、サイトが公開している表の比較です。

  • 全部同じ: 49個(1〜25画はすべて同じ)
  • 半吉を挟んで割れる: 26個(26・27・28・29・30・36・38・40・42・43・46・49・50・56・57・59・60・62・64・66・69・71・77・78・79・81)
  • 吉と凶で真逆に割れる: 6個(51・53・55・58・73・75)

人格と地格はほとんど25画以下に収まります(今の字で人格の89.7%、地格の100.0%)。つまり人格・地格では、表の違いはほとんど効きません。総格は26画以上になる人が多い(76.5%)ので、表の違いが出るのは主に総格です。ただ、割れ方はほとんどが「半吉か凶か」で、表だけの違いで吉と凶が入れ替わる人は0.1%でした。

All About の命名の解説には「全ての流派で合格する名前はありません」とあります。五格の吉凶だけを見るなら、ここで調べた範囲では当てはまらない名前もありました。ただ、実際の流派は陰陽の並びや五行の組み合わせなども見るので、それを足せばさらに減ります。この説が誤りだとまでは言えません。

細かい疑問に答える

新字体と旧字体、どっちが正しい？

決まった答えはありません。旧字体派は「姓名判断の体系は旧字体の時代に作られた」、新字体派は「いま戸籍に書かれ、使っている字で見るべき」と考えます。どちらも筋は通っていて、どちらかが正しいと確かめる方法がありません。実際の数字では、結果を動かしているのは字体より部首の数え方です。

霊数はあり？なし？

流派によります。Wikipedia は、足す流派も足さずにそのまま鑑定する鑑定士も多くいるとしています。総格に足さない点は多くの解説で共通です。1文字の姓・名の人は結果が大きく動くので、計算機で切り替えて見てください。

凶だらけでも大丈夫？

姓名判断に科学的な根拠はありません。画数と運勢の関係が確かめられたことはないので、凶の数で何かが決まるわけではありません。数字の上でも、凶が2つ以上ある人は47.8%いて、珍しくありません。

名付けで画数はどこまで気にする？

全部の流派を満たそうとすると、ほとんどの候補が残りません。12通りすべてで凶がない名前は5.3%です。気にするなら流派を1つ決めて、その中で見るのが現実的です。All About の解説も、混ぜて占うことはできないので流派を絞るしかない、としています。読みやすさや字の意味など、数え方で変わらないものを先に決めて、画数は最後に見るという順番もあります。

結婚で名字が変わると、どこが変わる？

名だけで決まる地格は変わりません。天格と総格は必ず計算し直しになり、人格は姓の最後の字が変わると動きます。外格は総格−人格なので、これも変わることがあります。

流派はいくつある？

All About の命名の解説では、30以上の流派があるとされています。天格・人格・地格・外格・総格の五格で見るやり方は、明治末から昭和初期に熊崎健翁らが広めたものが主流です。ただ、同じ「熊崎式」を名乗っていても、字体の扱いがサイトによって違うことがあります。

81画を超えたらどうする？

この扱いも資料によって違います。80を引く数え方と、81を引く数え方があります。熊崎健翁の原典は、81は1と同じ数に戻るとし、82以上は80を引いて読みます(82は2)。この計算機もその扱いです。今回数えた名前では、4通りのどの数え方でも81画を超える組み合わせはありませんでした。

熊崎健翁の原典と照らし合わせた

五格の方法を広めた熊崎健翁の『運命の神秘 附録・撰名字引』(実業之日本社、昭和5年)は、国立国会図書館デジタルコレクションでログインなしで読めます。この本の計算例・字引・81数の説明と、この記事の計算を突き合わせました。

  • 画数: 字引の前書きは、画数を康熙字典と簡野道明『字源』に従って決め、略字は正字の画数で数えるとしています。「表」は上の3画と「衣」の6画で9画、「泰」は水に属して9画、「酒」は酉の部なので水偏として数えない、などの例も載っています。この記事の「旧字体＋部首」の列は、原典の計算例と字引で読めた42字(原10・敬13・之4・蓮17・巖23・萬15 など)とすべて一致します
  • 霊数: 原典は「仮成数」と呼び、1文字の姓は上に1、1文字の名は下に1を足して天格・地格・外格を作り、総格には足しません。原敬の例は天格11・人格23・地格14・外格2・総格23で、計算機の「天格・地格・外格に足す」と同じ結果です。原敬・松方巖・星亨・沖禎介・田中義一・澁澤榮一など9人の計算例で、五格がすべて一致しました
  • 81を超えたとき: 81は1と同じ数に戻り、82以上は80を引いて読みます
  • 吉凶: 原典は1〜81画に「吉」「凶」の札を付けず、文章で説明しています。7つの公開表で吉と凶が真逆に割れた6つ(51・53・55・58・73・75)は、原典ではどれも「一盛一衰」「吉凶相半」のように、吉と凶の両方を書いた数でした。多数決の表では53だけを「凶」、残り5つを「半吉」にしています

2026年11月7日、原典と照らし合わせて「旧字体＋部首」の列を直しました。それまでは部首だけを元の字にしていたので、「之」「敬」「蓮」などが原典と1画以上違っていました。この記事の割合は、直したあとの数字です。

姓名判断はいつからあるのか

「姓名判断」という言葉の古い用例として、『精選版 日本国語大辞典』は1902年(明治35年)の東海日日新聞の「新式姓名判断」を挙げています。百科事典には、古代中国の文字占い(相字)が起源で、日本では中世以降に字画で見るようになったとする説明もあります。一方、いま広く見かける五格の方法は、明治末から昭和初期に熊崎健翁らが新聞や雑誌を通じて体系化したものが主流です(熊崎の『姓名の神秘』は実業之日本社から1929年6月、『運命の神秘』は昭和5年、『熊崎式姓名学大奥義』は五聖閣から昭和6年に出ています。いずれも国立国会図書館デジタルコレクションにあります)。

鑑定する側が「統計学に基づく」と言うことはありますが、学術的な統計で因果関係が示されたことはありません。このサイトも、姓名判断に科学的な根拠はないという立場です。そのうえで、「数え方を変えるとどれくらい結果が変わるか」のように計算で確かめられることだけを数えました。

数え方と、この集計の限界

  • 名字: 人名力の全国ランキング上位1,200個(推計人数の合計約8,906万人)。人数で重みをつけました
  • 2025年生まれの名前: 明治安田の2025年の名前ランキング上位231種類(調査で分かった人数で重み)
  • 全世代の名前: 明治安田の1912〜2025年の各年ベスト10、286種類(登場した回数で重み)。かなを含む名前は延べ60件を除きました
  • 組み合わせ: 名字と名前は独立に組み合わせました(2025年は277,200組、全世代は343,200組)。実在の人の分布ではありません
  • 画数: 常用漢字と人名用漢字は漢字辞典オンラインの総画、旧字体は Unihan と Wikipedia の常用漢字一覧、康熙字典の部首と部首内の画数は Unicode 15.0 の Unihan(kRSKangXi)。公開されている計算例と、熊崎健翁の原典の42字と照合しています。資料どうしで違う字があり、たとえば「辺」の旧字体「邊」は18画とする資料と19画とする資料があります
  • 吉凶: 7つの公開サイトの表の多数決。サイトの表なので、流派の公式の表とは限りません
  • 流派: 4通りは数え方の組み合わせで、流派そのものの再現ではありません。陰陽の並び、五行の組み合わせ(三才)、読みの音などは見ていません

計算は2つの別のプログラムで行い、結果が一致することを確かめました。

よくある質問

姓名判断の結果がサイトによって違うのはなぜですか？

画数の数え方が違うからです。部首を元の字で数えるか、旧字体に直すか、霊数を足すかが流派で分かれます。名字1,200個と名前で数えると、今の字と旧字体＋部首では、2025年の人気の名前の57.8%で人格・地格・総格のどれかの吉凶が変わりました。

新字体と旧字体はどちらで見るのが正しいですか？

決まった答えはありません。旧字体派は体系が旧字体の時代に作られたことを、新字体派はいま戸籍に書かれ使っている字であることを理由にします。数字の上では、結果を動かしているのは字体より部首の数え方です。

霊数は足すべきですか？

流派によります。姓か名が1文字の人は、天格・地格・外格に霊数を足すと91.3%の人で五格のどこかの吉凶が変わります。総格には足さないのが一般的です。

姓名判断で凶があるのは悪いことですか？

姓名判断に科学的な根拠はなく、凶で何かが決まるわけではありません。数えてみると、今の字で五格に凶が1つもない人は16.7%で、凶があるほうが普通です。

吉凶の表は流派で大きく違いますか？

7つの公開サイトの表を比べると、1〜25画はすべて同じで、割れるのは26画以上でした。真逆に割れるのは51・53・55・58・73・75画の6個だけです。

どの流派の結果を信じればいいですか？

正解はありません。気にするなら流派を1つ決めて、その中で見るのが現実的です。全部の数え方で凶がない名前は少なく、12通りすべてで凶がないのは5.3%です。
