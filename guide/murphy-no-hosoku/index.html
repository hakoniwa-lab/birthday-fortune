マーフィーの法則は本当か

一つずつ計算したら、本当のものと気のせいのものがきれいに分かれました

「洗濯すると靴下が片方だけなくなる」「バスは待っているときに限って来ない」「バタートーストはバターの面が下に落ちる」。こういうのをマーフィーの法則と呼びます。

もとは技術者の心得で、「起こりうる失敗は必ず起こる」という設計の考え方でした。それが1990年代に笑い話の本として広まって、いまの形になっています。

では全部ただの思い込みなのか。調べたら違いました。いくつかは計算でぴったり確かめられます。このページでは一つずつ数えて、本当のものと気のせいのものを分けました。

ここに出てくる数字はすべて、その場で計算したものです。引用ではありません。計算に使ったコードも最後に載せています。

本当でした: 靴下は片方だけなくなる

これは計算するとむしろ当たり前でした。両方いっしょになくなるほうが、はるかに難しいのです。

10足(20枚)持っていて、洗濯の途中で2枚どこかへ行ったとします。その2枚がたまたま同じペアだった確率は、20枚から2枚を選ぶ190通りのうち10通りだけ。つまり1/19、約5.3%です。

持っている足数2枚が同じペア片方だけが2つできる
5足(10枚)11.1%88.9%
10足(20枚)5.3%94.7%
15足(30枚)3.4%96.6%
20足(40枚)2.6%97.4%

たくさん持っているほど悪化します。整理しようと靴下を買い足すと、片方だけが残る確率は上がるわけです。

10足から5枚なくした場合も計算しました。完全に消えるペアは平均0.53組だけで、余った1枚は平均3.95枚。なくした枚数のほとんどが「片方だけ」になります。引き出しに片方が溜まるのは、運が悪いのではなく確率どおりです。

本当でした: 13日の金曜日は多い

これも本当です。しかも暦の構造から決まっている確定事実で、ゆらぎではありません。

グレゴリオ暦は400年でぴったり146,097日＝20,871週になります。週の切れ目とぴったり合うので、400年たつと曜日の並びが完全に元に戻ります。つまり400年ぶんを数えれば、それが永久の答えです。

400年間にある13日は4,800回。曜日別に数えるとこうなりました。

13日の曜日400年での回数
金曜日688
水曜日・日曜日687
月曜日・火曜日685
木曜日・土曜日684

均等なら685.7回なので、金曜日はいちばん多い側です。差はわずか4回ですが、何百年たっても縮まりません。

ちなみに次の13日の金曜日は2026年11月13日。そのあとは2027年8月13日、2028年10月13日、2029年4月13日です。

同じ計算のしかたで、六曜や一粒万倍日を月ごとに出しているのが吉日カレンダーです。暦は全部、計算で決まります。

本当でした: バスは待つと来ない

これがいちばん面白い結果でした。「10分間隔のバスなら平均5分待つ」は間違いです。

理由はこうです。バスの間隔がばらつくと、長く空いた時間帯のほうに、多くの乗客が入り込みます。2分の間隔に来る人はほとんどいませんが、18分空いた間隔には9倍の人が来ます。だから「乗客が体験した待ち時間」の平均は、間隔の半分より長くなります。

待ち時間の平均は、間隔の二乗の平均を、間隔の平均の2倍で割った値になります。実際に計算し、あわせて200万人ぶんのシミュレーションでも確かめました。

バスの来かた計算値シミュレーション
きっちり10分間隔5.00分5.00分
5〜15分でばらつく5.42分5.42分
半分は2分・半分は18分(団子運転)8.20分8.20分
完全にランダム9.99分9.98分

いちばん下を見てください。平均10分間隔なのに、待ち時間の平均も約10分。「半分の5分」ではありません。ダイヤが乱れて団子運転になるほど、体感の待ち時間は伸びていきます。

つまり「待つと来ない」は気のせいではなく、バスが不規則なら必ずそうなるという数学です。逆に言えば、正確に運行されているバスでは起きません。

本当でした: 隣のレジのほうが早い

これは計算するまでもない話でした。レジがN列あれば、自分の列がいちばん早い確率は1/Nです。

レジの数自分がいちばん早いどこかの列が自分より早い
2列50%50%
3列33%67%
4列25%75%
5列20%80%

3列なら3回に2回は隣のほうが早い。5列なら80%です。当たり前ですが、これを「自分だけ運が悪い」と感じるのが人間だということです。

同じ理屈は道路の車線でも、レジ待ちの行列でも成り立ちます。自分が最良を引ける確率は、選択肢の数だけ薄まります。

本当でした: 急いでいるときは信号が赤

これも数字にすると納得できました。信号を何個も連続で青で通るのは、そもそも非常に難しいのです。

ある方向が青になっている割合を4割とすると、通る信号が増えるごとにこうなります。

通る信号の数青が4割のとき青が5割のとき
3個6.4%12.5%
5個1.0%3.1%
8個0.07%0.4%
10個0.01%0.1%

信号5個を全部青で抜けられるのは、100回に1回。これでは「今日は赤ばかりだ」と感じるのが普通です。急いでいない日も同じ確率で赤に引っかかっていますが、そちらは覚えていません。

※ 実際の信号は連動している区間もあるので、この計算はばらばらに独立していると考えた場合のものです。

本当でした: バタートーストはバターの面が下

これは物理の問題で、実際に研究されています。机から滑り落ちたトーストは、床に着くまでにちょうど半回転くらいしかしません。上を向いていたバターの面が、ぴったり下に来るわけです。

ここから先は計算できます。落下時間は高さの平方根に比例します。回転の速さが同じなら、回る角度も高さの平方根に比例します。机の高さ75センチで半回転(180度)だとすると、

落ちる高さ落下時間回る角度着地
40cm(低いテーブル)0.29秒131度バターが下
75cm(ふつうの机)0.39秒180度バターが下
1m0.45秒208度バターが下
1.7m0.59秒270度ここで上に戻る
3m0.78秒360度一回転してバターが上

バターの面が上に戻るには、机の2.25倍＝約1.7メートルの高さが必要です。一回転させるなら4倍の3メートル。人間の腰の高さの机では、どうやってもバターの面が下に来ます。

つまりこれは運の話ではなく、人間の机の高さがちょうど半回転ぶんだったという話です。もし人類が身長3メートルだったら、この法則は存在しませんでした。

※ 回転の速さは滑り出し方で変わります。ここでは「机の高さでちょうど半回転する」という研究結果を出発点にして、そこから高さを変えた場合を計算しています。

気のせいでした: 雨男・雨女

ここからは計算すると消えるものです。

「自分が出かけると雨が降る」。これを確かめるには、ただの偶然でどれくらい起こるかを先に知る必要があります。雨の日が3割の土地で10回出かけたとして計算しました。

10回のうち確率1万人なら
6回以上が雨4.7%474人
7回以上が雨1.1%106人
8回以上が雨0.16%16人
10回とも雨0.0006%0.1人

「10回出かけて7回雨」はかなり雨男らしい記録ですが、1万人いれば106人に起こります。学校や職場の規模でも、必ず何人かは該当します。

もっと決定的なのがこちらです。100回の外出のうち、どこかに5回連続の雨がある確率を数えたら15.2%でした。つまり7人に1人は「5回続けて雨だった」という記録を持っています。

100回の外出のうちどこかに起こる確率
4回連続の雨がある43.2%
5回連続の雨がある15.2%
6回連続の雨がある4.8%

雨男が生まれる仕組みはこうです。連続で雨が降ったあとに「雨男」と呼ばれ始めます。降らなかった人は何も言われません。だから世の中には雨男しかいなくて、「晴れ男でも雨男でもないふつうの人」は話題にならないのです。

これは確かめられる話でもあります。出かけた日の天気を記録して、その土地の降水日の割合と比べればいい。数か月で答えが出ます。占いと違って、雨男は検証できる主張です。そして検証すると、たいてい消えます。

本当だけれど、原因が自分ではないもの

「自分が店に入ると、後から客がどんどん来る」。これは実際に起きていることがあります。ただし原因はあなたの体質ではありません。

人は誰もいない店に入りにくく、何人かいる店には入りやすいためです。あなたが1人目になると、通りかかった人にとってその店は「入れる店」に変わります。2人目が入れば3人目はもっと入りやすくなります。あなたが呼んだのではなく、あなたが最初のきっかけになったという順番です。

行列ができる店とできない店が分かれるのも同じ仕組みで、味の差だけでは説明できないほど大きな差になります。

※ この節は仕組みの説明で、このページの他の項目と違って数字の計算はしていません。店ごとの実データがないと確かめられないためです。

言葉のトリックだったもの

「探し物は、いつも最後に見る場所にある」。これは法則でも偶然でもありません。

見つかったら探すのをやめるので、見つけた場所が必ず「最後に見た場所」になります。反例が存在しない言い方です。

この手のものは他にもあります。「本当に必要なものは、いつも見つからない」も、見つかったものは「本当に必要ではなかった」と後から言い換えられます。どう転んでも当たる言い方は、何も言っていないのと同じです。

整理すると5種類ありました

ここまで計算してみて、マーフィーの法則は一つの法則ではなく、性質の違う5種類の寄せ集めだと分かりました。

種類例
確率が本当に偏っている靴下・バス・レジ・信号・13日の金曜日
物理で決まっているバタートースト
本当だが原因が自分ではない店に客が来る
記憶の偏りだけ雨男・雨女
言葉のトリック探し物は最後に見る場所にある

「なんとなく当たる」と感じるのは、本当に当たるものが混ざっているからです。全部でたらめなら、ここまで語り継がれていません。

そして覚えているかどうかで結論が変わるものは、記録を取れば答えが出ます。雨男がそうでした。当たると感じたときに、それがどの種類なのかを一度考えてみると、案外はっきりします。

占いとどう違うのか

このサイトは占いのアプリを置いています。矛盾しているように見えるかもしれないので、立場を書いておきます。

占いと雨男は、性質がまったく違います。雨男は「出かけると雨が降る」という事実についての主張なので、記録を取れば正しいか間違っているかが決まります。一方、生年月日と性格の関係は確かめられた根拠がなく、そもそも当たり外れを測る土台がありません。

だからこのサイトでは、占いを「当てるもの」として出していません。出しているのは計算そのものです。旧暦も二十四節気もマヤ暦も、誰が計算しても同じ答えになります。根拠はないが、計算は同じ。この線だけは崩さないようにしています。

よくある質問

靴下はなぜ片方だけなくなるのですか？

両方いっしょになくなる確率がとても低いからです。10足(20枚)持っていて2枚なくす場合、その2枚が同じペアである確率は1/19、約5.3%しかありません。残りの94.7%では、別々のペアから1枚ずつ消えて「片方だけ」が2つできます。持っている足数が多いほどこの確率は下がり、20足なら1/39、約2.6%です。

13日の金曜日は本当に多いのですか？

多いです。グレゴリオ暦は400年でぴったり20,871週なので完全に繰り返します。その400年間にある4,800回の13日を曜日別に数えると、金曜日が688回でいちばん多く、木曜日と土曜日が684回でいちばん少なくなります。均等なら685.7回なので、金曜日はわずかに多い側です。これは偶然ではなく暦の構造から決まっています。

バスは待っているときに限って来ないのですか？

統計の上では本当です。平均10分間隔でも、間隔がばらつくと乗客が体験する平均待ち時間は5分を超えます。長く空いた時間帯のほうに多くの乗客が入り込むためで、待ち時間の平均は間隔の二乗の平均を間隔の平均の2倍で割った値になります。間隔が完全にランダムな場合、平均10分間隔でも待ち時間の平均は約10分です。

バタートーストはバターの面が下になって落ちるのですか？

机の高さでは下になりやすいです。落下時間は高さの平方根に比例するので、回転する角度も高さの平方根に比例します。机の高さ75センチで半回転するとすれば、バターの面が上に戻るには270度回る必要があり、高さは2.25倍の約1.7メートル必要です。一回転させるには4倍の3メートルが必要になります。

雨男・雨女は本当にいるのですか？

計算すると消えます。雨の日が3割の土地で10回出かけた場合、7回以上が雨になる確率は約1.1%です。低そうに見えますが、1万人いれば約106人に起こります。さらに100回の外出のうちどこかに5回連続の雨がある確率は15.2%で、7人に1人は「5回続けて雨だった」という記録を持ちます。珍しくない出来事を、あとから特別なことだと考えているだけです。

この記事の数字について

すべてこのページのために計算したものです。引用や推計ではありません。

  • 靴下・レジ・信号・雨男 — 組み合わせと確率の式から厳密に計算
  • 13日の金曜日 — 2001年から2400年までの4,800回をすべて数え上げ
  • バスの待ち時間 — 式による計算と、200万人ぶんのシミュレーションの両方。小数第2位まで一致
  • 5回連続の雨 — 100回の外出を20万通りシミュレーション
  • バタートースト — 落下時間から。「机の高さで半回転」を出発点にした相対計算
計算に使ったコードを見る 
from math import comb, sqrt
import numpy as np

# 靴下: 10足(20枚)から2枚なくして、同じペアである確率
n = 10
print(n / comb(2 * n, 2))                    # 0.0526... = 1/19

# 13日の金曜日: 400年で完全に繰り返すので数え上げる
cnt = [0] * 7
for y in range(2001, 2401):
    for m in range(1, 13):
        cnt[jdn(y, m, 13) % 7] += 1          # 月曜=0
print(cnt)                                    # 金曜(添字4)が688で最多

# バスの待ち時間: E[W] = E[X^2] / (2 E[X])
x = np.array([2.0] * 500 + [18.0] * 500)      # 半分2分・半分18分
print((x ** 2).mean() / (2 * x.mean()))       # 8.2 分

# バタートースト: 落下時間は高さの平方根に比例する
G = 9.80665
for h in (0.75, 1.69, 3.00):
    print(h, 180 * sqrt(h / 0.75))            # 180度 / 270度 / 360度

# 雨男: 雨が3割の土地で、100回の外出に5連続の雨があるか
rng = np.random.default_rng(20260912)
a = rng.random((200000, 100)) < 0.3
run = np.zeros(len(a), dtype=int); best = np.zeros(len(a), dtype=int)
for j in range(100):
    run = np.where(a[:, j], run + 1, 0)
    best = np.maximum(best, run)
print((best >= 5).mean())                     # 0.152
