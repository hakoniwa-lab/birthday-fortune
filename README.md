# 生まれ日診断 (birthday-fortune)

生年月日を入れるだけで、**西洋占星術の出生図**(太陽・月・水星・金星・火星・木星・土星、アセンダント)と**四柱推命の命式**、数秘術のライフパスナンバー・九星気学の本命星・干支・月齢・誕生石を一度に表示し、日替わりの「今日の運勢」も出すWebアプリ。HAKONIWA LABの11本目。生まれた時刻と場所は任意入力。

## なぜ作ったか(2026-09-09)

既存の10本が全部お金・仕事・健康(YMYL)のジャンルで、検索評価もAdSense審査も厳しい側に寄っていた。占いは**非YMYL**で、入力→計算→結果のジェネレーター型なので既存の骨格がそのまま使える。「占いは統計学」ではないが、アプリの価値は当たることではなく「自分のことを考えるきっかけ」にある、という立場で作っている。ページ内でも根拠がないことを正直に書いている(バーナム効果の説明まで入れた)。

## 計算ロジック(fortune.js — 数秘・九星・干支・月齢)

| 項目 | 方法 | 検証済みの値 |
|---|---|---|
| ライフパスナンバー | 年・月・日を個別に還元→合計→還元。11/22/33は残す | 1990/12/25→11 |
| 本命星 | 立春基準の年の各桁和を1桁にして 11−n(10→1, 0→9) | 2000→九紫、1990→一白、1985→六白、2024→三碧、1990/1/15→二黒(前年) |
| 立春 | astro.js の節気計算(太陽視黄経315度の瞬間) | 1984→2/5、2020→2/4、2021→2/3 23:58、2025→2/3 |
| 干支 | 1984=甲子、暦年基準。立春基準で前年になる場合は注記を出す | 2026→丙午 |
| 星座 | 太陽の実際の視黄経から算出(早見表は使わない) | 1990/3/20→魚、1990/3/21→牡羊、2024/12/21→射手、12/22→山羊 |
| 月齢 | 2000-01-06 18:14 UTC の新月から朔望月29.530589日、正午JSTで評価 | 2024/9/18→14.5(満月) |
| 今日の運勢 | `生年月日|今日` の文字列→xmur3→mulberry32 の疑似乱数 | 同じ日は同じ結果、翌日は変わる |

- 総合運の星は 1:6% / 2:18% / 3:34% / 4:30% / 5:12% に寄せてある(2000日で実測 128/345/700/607/220)
- 干支を**暦年基準**にしたのは年賀状で使う一般的な感覚に合わせるため。九星・四柱推命は立春基準なので、両者がずれる1月〜節分生まれには注記を出す

## 保存

`localStorage` の `birthday-fortune:birth` に `{y,m,d,hour,minute,pref}` を入れ、次回開いたときに今日の運勢を即表示する(再訪の理由づくり)。**旧形式 `{y,m,d}` も読める**(時刻・場所が無ければ未入力として扱う)。「別の生年月日で診断する」で消す。読み書きは try/catch で包み、使えなくても動く。

## 2026-09-10 追加 — 西洋占星術(出生図)と四柱推命(命式)

「西洋占星術と四柱推命も追加して」という依頼で、太陽星座だけだった占星術を出生図まで広げ、四柱推命を新規に実装した。あわせて**入力に「生まれた時刻」と「生まれた場所」(どちらも任意)** を足した。

### 入力を増やすと何が出るか

| 入力 | 増えるもの |
|---|---|
| 生年月日のみ | 月星座は正午で概算・時柱は出ない(その旨を画面に明示) |
| ＋ 生まれた時刻 | 月星座が正確に / 四柱推命の**時柱** / 立春当日の年の判定が確定 |
| ＋ 生まれた場所 | **アセンダント**とMC / 時支の地方時補正 |

保存形式は `{y,m,d,hour,minute,pref}` に拡張した。**旧形式 `{y,m,d}` も読めるようにしてある**(hour/pref が無ければ未入力として扱う)。

### astro.js — 天文計算

| 対象 | 方法 | 検証 |
|---|---|---|
| 太陽 | Meeus 25章の簡約式 + 惑星摂動5項 | Meeus 例25.a の**視黄経** 199.90895 と一致(誤差0.00001度) |
| 月 | Meeus 47章の主要26項 | Meeus 例47.a 133.162655 に対し 133.15997(0.003度) |
| 惑星 | JPL 近似軌道要素(1800-2050)+ケプラー方程式 | 2020-12-21 の木星土星大接近で両者 300.2度に一致。水星の最大離角27.8度・金星47.1度 |
| 二十四節気 | 太陽視黄経が目標値になる瞬間を二分法 | 国立天文台の立春と全年一致(1984=2/5, 2021=2/3 23:58, 2025=2/3) |
| アセンダント | グリニッジ平均恒星時+黄道傾斜角から算出 | MCとの前後関係で象限を確定 |

**ΔT(地球時−世界時)を必ず入れる。** 天体位置の式はTT基準、暦の日時はUT基準。約70秒の差だが、2021年の立春(23:58)のように**日付が変わる境目**では効く。NASAの近似多項式を使用。

**惑星摂動項を省くと視黄経が0.003度ずれ、節入りが3〜4分早く出る。** 省いた版と入れた版で1984/2021/2024/2025を比べ、4年とも公式値に近づくことを確認して採用した。これは Meeus の低精度版(例25.a)と VSOP87版(例25.b)の差そのもの。

### 踏んだ落とし穴

1. **`solarTermJd` を黄経から月を逆算する作りにしたら、小寒(285度)で翌年1月の小寒を拾った。** 年柱が丸ごと1年ずれる。→ 節ごとに探す月を表に持たせ、月初の2日前から20日間だけを見るようにした
2. **地方時の経度補正を、節入りの判定にまで掛けていた。** 節入りは天文現象なので、どこで生まれても同じ瞬間に起きる。補正して比べると立春の前後1時間に生まれた人の年柱が九星気学とずれる(1922・1951・2025年で実際に発生)。→ **補正は時支を決めるときだけ**に限定
3. **九星は「日」単位、四柱推命は「瞬間」で立春を判定していて、立春当日に食い違った。** → `kyuseiYear` も瞬間で判定するように統一。時刻未入力で立春当日生まれの場合は `risshunAmbiguous` を立てて画面に注意書きを出す
4. **星座を早見表(3/21〜4/19が牡羊座…)で出していたため、出生図の太陽と境目でずれる可能性があった。** → プロフィール欄の星座も実際の太陽視黄経から出すようにして、必ず一致させた

### 総当たり検証

1920〜2026年 × 境目になりやすい11日付 × 時刻4パターン = **4,388件で例外0・矛盾0**。確認した不変条件:

- プロフィールの星座 == 出生図の太陽の星座
- プロフィールの干支(立春基準) == 四柱推命の年柱
- 日柱が1日ずつ60周期で連続する(800日連続で確認)
- 立春が必ず2/3〜2/5に入る(1920-2050)
- 時刻未入力なら時柱もアセンダントも null になる

検算した命式: 2000-01-01 12:00 → 己卯/丙子/戊午/戊午、1990-12-25 07:30東京 → 庚午/戊子/甲子/戊辰(十二運=沐浴、空亡=戌亥、通変星=偏官/偏財)。

### 流派による違い(そのまま採用した判断)

- **日の変わり目は0時**。23時以降を翌日の日柱とする流派もある
- **時支の地方時補正は行う**(明石135度基準)。行わない流派もある。均時差までは見ていない(地方平均時)
- **干支の表示は暦年基準**(年賀状の感覚)。立春基準で前年になる場合は注記を出す
- 1948〜1951年の夏時刻(サマータイム)は補正していない。この4年の夏に生まれた方は時刻を1時間戻して入力する必要がある

## 2026-09-12 追加 — 吉日カレンダー・相性診断・解説記事

### 吉日カレンダー(`calendar/`)

六曜は旧暦の(月＋日)÷6 で決まるので、**旧暦そのものを計算する必要がある**。`js/koyomi.js` に天保暦の手順を実装した:

1. 朔(新月)は Meeus の平均朔で当たりをつけ、月と太陽の黄経差が0になる点をニュートン法で追い込む(1日あたり約12.19度で割る)
2. 冬至を含む朔望月が十一月。翌年の冬至までに朔望月が13個あれば閏年で、十一月の次から見て**最初に中気を含まない月**が閏月
3. 朔日は**日本時間の日付**で決める(UT の JDN d は JST では [d-0.875, d+0.125])

**検証**(すべて一致): 旧正月 2020=1/25、2023=1/22、2024=2/10、2025=1/29、2026=2/17 / 中秋の名月 2023=9/29、2024=9/17、2025=10/6 / 閏月 2023=閏2月(3/22〜)、2025=閏6月(7/25〜)、2028=閏5月 / 旧暦各月1日の六曜が 先勝・友引・先負・仏滅・大安・赤口 の順

**暦注の出現数**(2025/2026年): 一粒万倍日 59/62(定説約60)、天赦日 5/6、寅の日30/31、己巳の日6/6、不成就日 47/49、三隣亡 29/32、六曜は各60〜62で均等。2025年の天赦日 3/10・5/25・7/24・10/6・12/21 は公開されている暦と一致。

**扱っている暦注と根拠**: 六曜(旧暦)、日の干支、十二直(節月支と日支の差)、一粒万倍日(節月×日支の表)、天赦日(季節×干支)、寅の日・巳の日・己巳の日、不成就日(旧暦月日の表)、三隣亡(節月×日支)。**二十八宿は起点の流儀が複数あるので扱わない**。一粒万倍日・不成就日・三隣亡の表は資料差があるので画面に明記。

**十二直は節入りの日に前日と同じ直が2日続く**(白露で 9/7・9/8 が両方「建」)。仕様どおりなので直さない。

**キャッシュ必須**: 1か月分で `solarTermJd` を何百回も呼ぶ。`astro.js`(節気)・`chart.js`(3年分の節の並び)・`koyomi.js`(朔と月立て)にそれぞれ Map キャッシュを入れて、初回6ms・月送り1ms。

### 年運・月運(九星の回座)

疑似乱数だけだと薄いので、**九星気学の「回座」を骨**にした。本命星が年盤・月盤のどの宮にいるかで
9段階(八方塞がり→上昇→収穫→変化→頂点→冬眠→準備→発展→好調)が決まり、9年/9か月で一周する。

- 年盤中宮 = 本命星と同じ式。毎年1つ減る(2026=一白)
- 月盤中宮 = 年の十二支で寅月が決まり(子午卯酉=八白/辰戌丑未=五黄/寅申巳亥=二黒)、月ごとに1つ減る
- 回座 `((本命星 - 中宮 + 4) mod 9) + 1` … 5が中宮=八方塞がり。中宮から1つずつ増えると 乾→兌→艮→離→坎→坤→震→巽 の順になる

星の数は段階ごとの基準値±1に留める(完全な乱数にすると周期と食い違って意味が消える)。
**年運・月運の星は下限2**。1年ずっと星1つは読んでいて気分が良くないため(日運は1も出る)。
