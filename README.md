# 生まれ日診断 (birthday-fortune)

生年月日を入れるだけで、数秘術のライフパスナンバー・九星気学の本命星・干支・星座・生まれた曜日・月齢・誕生石を一度に表示し、日替わりの「今日の運勢」も出すWebアプリ。HAKONIWA LABの11本目。

## なぜ作ったか(2026-09-09)

既存の10本が全部お金・仕事・健康(YMYL)のジャンルで、検索評価もAdSense審査も厳しい側に寄っていた。占いは**非YMYL**で、入力→計算→結果のジェネレーター型なので既存の骨格がそのまま使える。「占いは統計学」ではないが、アプリの価値は当たることではなく「自分のことを考えるきっかけ」にある、という立場で作っている。ページ内でも根拠がないことを正直に書いている(バーナム効果の説明まで入れた)。

## 計算ロジック(fortune.js)

| 項目 | 方法 | 検証済みの値 |
|---|---|---|
| ライフパスナンバー | 年・月・日を個別に還元→合計→還元。11/22/33は残す | 1990/12/25→11 |
| 本命星 | 立春基準の年の各桁和を1桁にして 11−n(10→1, 0→9) | 2000→九紫、1990→一白、1985→六白、2024→三碧、1990/1/15→二黒(前年) |
| 立春 | 2021-02-03 23:59 JST を起点に 365.2422日/年 の線形モデル | 1984→2/5、2020→2/4、2021→2/3、2025→2/3 |
| 干支 | 1984=甲子、暦年基準。立春基準で前年になる場合は注記を出す | 2026→丙午 |
| 星座 | 一般的な早見表の区切り | 1/19→山羊、1/20→水瓶 |
| 月齢 | 2000-01-06 18:14 UTC の新月から朔望月29.530589日、正午JSTで評価 | 2024/9/18→14.5(満月) |
| 今日の運勢 | `生年月日|今日` の文字列→xmur3→mulberry32 の疑似乱数 | 同じ日は同じ結果、翌日は変わる |

- 立春は線形モデルなので、実際の天文計算と数十分ずれる。境目ぴったりの年(23:5x に立春が来る年)は1日違う可能性がある。ページにも「前後する可能性」を書いてある
- 総合運の星は 1:6% / 2:18% / 3:34% / 4:30% / 5:12% に寄せてある(2000日で実測 128/345/700/607/220)
- 干支を**暦年基準**にしたのは年賀状で使う一般的な感覚に合わせるため。九星・四柱推命は立春基準なので、両者がずれる1月〜節分生まれには注記を出す

## 保存

生年月日だけを `localStorage` の `birthday-fortune:birth` に入れ、次回開いたときに今日の運勢を即表示する(再訪の理由づくり)。「別の生年月日で診断する」で消す。読み書きは try/catch で包み、使えなくても動く。
